# SPEC-STOCK-035 수용 기준 (Acceptance Criteria)

> EARS 수용 기준 + Given-When-Then BDD 시나리오 + 엣지 케이스 + Definition of Done.
> REQ-RPT-001~005 및 NFR-001~005에 대응한다.

---

## 1. EARS 수용 기준 (AC)

### AC-RPT-001 (REQ-RPT-001, CSV 보유 손익 리포트)

- WHEN 사용자가 자신이 소유한 포트폴리오의 CSV 리포트를 요청하면 THE 시스템 SHALL 보유 종목 수와 동일한 데이터 행을 가진 다운로드 가능한 파일을 반환한다.
- THE 시스템 SHALL CSV의 각 데이터 행에 종목 코드·종목명·수량·평균 단가·현재가·평가 손익 금액·수익률·비중을 순서대로 포함한다.
- THE 시스템 SHALL CSV 보고서 응답에 첨부 파일로 다운로드할 수 있도록 다운로드 지시 헤더를 포함한다.

### AC-RPT-002 (REQ-RPT-002, JSON 통합 요약)

- WHEN 사용자가 자신이 소유한 포트폴리오의 JSON 리포트를 요청하면 THE 시스템 SHALL 포트폴리오 식별자·생성 시각·기간·총 평가액·총 수익률을 포함한 구조화 문서를 반환한다.
- THE 시스템 SHALL JSON 요약 문서에 보유 종목 상세 목록을 포함한다.
- WHERE 배당 데이터가 가용하면 THE 시스템 SHALL JSON 요약 문서에 배당 요약 정보를 포함한다.
- WHERE 벤치마크가 지정되면 THE 시스템 SHALL JSON 요약 문서에 벤치마크 비교 정보를 포함한다.

### AC-RPT-003 (REQ-RPT-003, 커스텀 날짜 범위)

- WHEN 커스텀 시작일과 종료일이 함께 제공되면 THE 시스템 SHALL 표준 기간이 아닌 해당 범위의 포트폴리오 수익률을 산출하여 반환한다.
- THE 시스템 SHALL 커스텀 날짜 범위 요청에 대해 해당 범위를 기간 식별자로 반영하여 표준 기간 코드가 아닌 커스텀 범위 식별자를 응답에 포함한다.

### AC-RPT-004 (REQ-RPT-004, 월별 스냅샷)

- WHEN 사용자가 자신이 소유한 포트폴리오의 특정 월 스냅샷 생성을 요청하면 THE 시스템 SHALL 해당 월의 총 평가액·기간 수익률·보유 종목 수를 저장하고 저장된 스냅샷을 반환한다.
- THE 시스템 SHALL 월별 스냅샷에 요청된 월 식별자를 저장한다.

### AC-RPT-005 (REQ-RPT-005, 소유권·포맷 검증)

- IF 사용자가 소유하지 않은 포트폴리오에 대해 리포트를 요청하면 THEN THE 시스템 SHALL 존재하지 않는 포트폴리오에 대한 요청과 동일하게 응답한다.
- IF 지원하지 않는 리포트 포맷이 요청되면 THEN THE 시스템 SHALL 지원되는 포맷을 안내하는 오류를 반환한다.

### AC-RPT-NFR-001 (REQ-RPT-NFR-001, 라이브러리 비도입)

- THE 시스템 SHALL 보고서 생성 시 표준 수학 연산 및 프로젝트 승인 수치 라이브러리만 사용하며 신규 외부 통계·최적화 라이브러리를 사용하지 않는다.

### AC-RPT-NFR-002 (REQ-RPT-NFR-002, CSV 표준 라이브러리)

- THE 시스템 SHALL CSV 직렬화에 외부 CSV 파싱 라이브러리를 사용하지 않고 언어 표준 입출력 유틸리티만을 사용한다.

### AC-RPT-NFR-003 (REQ-RPT-NFR-003, 순수 함수 테스트성)

- THE 시스템 SHALL 보유 손익행 생성 및 CSV 직렬화 기능을 데이터베이스·외부 캐시·외부 네트워크 의존 없이 입력값만으로 결정적으로 수행한다.

### AC-RPT-NFR-004 (REQ-RPT-NFR-004, 스냅샷 멱등성)

- IF 동일 포트폴리오·동일 월 스냅샷 생성이 재요청되면 THEN THE 시스템 SHALL 중복 레코드를 생성하지 않고 단일 레코드를 유지하며 값을 갱신한다.

### AC-RPT-NFR-005 (REQ-RPT-NFR-005, 응답성)

- THE 시스템 SHALL 최대 50개 보유 종목 포트폴리오에 대한 리포트 생성을 5초 이내에 완료한다.

## 2. Given-When-Then BDD 시나리오

### BDD-1: CSV 리포트 다운로드 (정상 경로)

```
Given 사용자가 3개 보유 종목을 가진 자신의 포트폴리오를 소유한다
  And 각 보유 종목의 현재가가 확보되어 있다
When 사용자가 해당 포트폴리오의 CSV 리포트를 요청한다
Then 시스템은 첨부 다운로드 헤더를 가진 CSV 파일을 반환한다
  And CSV는 헤더 1행 + 보유 종목 3행으로 구성된다
  And 각 행은 종목코드·종목명·수량·평균단가·현재가·평가손익·수익률·비중을 포함한다
```

### BDD-2: JSON 통합 요약 (배당·벤치마크 포함)

```
Given 사용자가 자신의 포트폴리오를 소유한다
  And 배당 데이터와 KOSPI 벤치마크 데이터가 가용하다
When 사용자가 benchmark=KOSPI, period=YTD로 JSON 요약 리포트를 요청한다
Then 시스템은 포트폴리오 요약·기간 성과·배당 요약·벤치마크 비교를 묶은 문서를 반환한다
  And 문서의 holdings 목록이 보유 종목 상세를 포함한다
  And 문서의 dividend_summary가 배당 요약을 포함한다
  And 문서의 benchmark가 벤치마크 비교를 포함한다
```

### BDD-3: 커스텀 날짜 범위 리포트

```
Given 사용자가 자신의 포트폴리오를 소유한다
When 사용자가 시작일 2026-01-01, 종료일 2026-03-31로 리포트를 요청한다
Then 시스템은 표준 기간이 아닌 해당 범위의 포트폴리오 수익률을 산출한다
  And 응답의 기간 식별자가 커스텀 범위를 나타낸다
```

### BDD-4: 월별 스냅샷 생성·재생성 (멱등성)

```
Given 사용자가 자신의 포트폴리오를 소유한다
When 사용자가 month="2026-05" 스냅샷 생성을 요청한다
Then 시스템은 총 평가액·기간 수익률·보유 종목 수를 저장하고 스냅샷을 반환한다
When 사용자가 동일 포트폴리오에 month="2026-05" 스냅샷 생성을 다시 요청한다
Then 시스템은 중복 레코드를 만들지 않고 기존 레코드를 갱신한다
  And 해당 포트폴리오·월 조합의 레코드 수가 1을 유지한다
```

### BDD-5: 소유권 위반 (정보 비노출)

```
Given 포트폴리오가 다른 사용자에게 속한다
When 요청 사용자가 해당 포트폴리오의 리포트를 요청한다
Then 시스템은 존재하지 않는 포트폴리오에 대한 요청과 동일하게 응답한다
  And 포트폴리오 존재 여부나 소유자 정보를 노출하지 않는다
```

### BDD-6: 미지원 포맷 요청

```
Given 사용자가 자신의 포트폴리오를 소유한다
When 사용자가 지원하지 않는 포맷(예: pdf)으로 리포트를 요청한다
Then 시스템은 지원되는 포맷(CSV·JSON)을 안내하는 오류를 반환한다
```

### BDD-7: 스냅샷 목록 조회

```
Given 사용자가 자신의 포트폴리오에 대해 여러 월의 스냅샷을 저장해 두었다
When 사용자가 스냅샷 목록을 요청한다
Then 시스템은 저장된 스냅샷 목록을 월 오름차순으로 반환한다
```

## 3. 엣지 케이스

| # | 상황 | 기대 동작 |
|---|------|-----------|
| E-1 | 보유 종목이 0개인 포트폴리오 | CSV는 헤더만(데이터 행 0), JSON 요약 holdings는 빈 목록, 총액 0 |
| E-2 | 일부 종목 현재가 미확보 | service 관례대로 매수가 대체·수익률 0 처리, 임의 값 단언 금지(§2.2 제외) |
| E-3 | 평균단가 0인 종목 | 수익률 0 처리(division-by-zero 가드) |
| E-4 | 포트폴리오 총액 0 | 모든 비중 0 처리 |
| E-5 | 해외(USD) 종목 포함 | 환율 적용하여 KRW 단위로 금액 표기 |
| E-6 | 배당 데이터 미확보 | JSON 요약 dividend_summary는 None(생략) |
| E-7 | 벤치마크 미지정 | JSON 요약 benchmark는 None(생략) |
| E-8 | 벤치마크 데이터 미확보 | 벤치마크 비교의 미산정 필드는 None(034 graceful degradation 위임) |
| E-9 | 커스텀 범위 데이터 2일 미만 | 범위 수익률 미산정(has_data=False 관례), 오류 미발생 |
| E-10 | 스냅샷 월 형식 오류("2026-13" 등) | 유효성 오류 반환 |
| E-11 | 동일 포트폴리오·월 스냅샷 동시 재요청 | 단일 레코드 유지(upsert 멱등성) |
| E-12 | 한국어 종목명 CSV | UTF-8 BOM으로 Excel 한국어 정상 표기 |
