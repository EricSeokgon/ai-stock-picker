# SPEC-STOCK-038 Acceptance Criteria

Format: EARS (Event-driven / Unwanted / Ubiquitous / State-driven)
Subject: THE 시스템 SHALL

---

## AC-1: 가치 시계열 데이터 반환 (REQ-DASH-001)

WHEN 사용자가 허용된 기간(7일/30일/90일/365일)을 지정하여 가치 시계열을 요청하면, THE 시스템 SHALL 해당 기간 내 월별 스냅샷을 날짜 오름차순으로 정렬한 (date, total_value_krw) 쌍의 목록을 반환한다.

## AC-2: 빈 기간 시 빈 배열 반환 (REQ-DASH-001)

IF 지정 기간 내 스냅샷이 존재하지 않으면, THEN THE 시스템 SHALL 오류 없이 빈 배열을 반환한다.

## AC-3: 섹터 집계 데이터 반환 (REQ-DASH-002)

WHEN 사용자가 섹터 집계를 요청하면, THE 시스템 SHALL 보유 종목을 섹터별로 묶어 각 섹터의 현재 평가액과 수익률(%)을 포함한 목록을 반환한다.

## AC-4: 섹터 미분류 종목 처리 (REQ-DASH-002)

IF 보유 종목에 섹터 정보가 없는 항목이 있으면, THEN THE 시스템 SHALL 해당 종목을 "기타/해외" 섹터로 분류하여 집계에 포함한다.

## AC-5: 자산유형 배분 데이터 반환 (REQ-DASH-003)

WHEN 사용자가 자산유형 배분을 요청하면, THE 시스템 SHALL 보유 종목을 국내(KRX)와 해외(NYSE/NASDAQ)로 구분하여 각 유형의 평가액과 전체 대비 비중(%)을 반환한다.

## AC-6: 자산유형 배분 비중 합계 (REQ-DASH-003)

THE 시스템 SHALL 자산유형 배분 응답에서 모든 유형의 비중(%)의 합이 100이 되도록 계산한다.

## AC-7: 벤치마크 비교 차트 재사용 (REQ-DASH-004)

THE 시스템 SHALL 벤치마크 비교 데이터를 기존 벤치마크 비교 기능(SPEC-034)을 통해 제공하며 별도 백엔드 로직을 재구현하지 않는다.

## AC-8: 대시보드 4종 차트 렌더 (REQ-DASH-005)

WHEN 사용자가 대시보드 화면에 진입하면, THE 시스템 SHALL 가치 시계열·섹터 집계·자산유형 배분·벤치마크 비교 4종 차트를 반응형 그리드로 표시한다.

## AC-9: 기간 전환 시 차트 갱신 (REQ-DASH-006)

WHEN 사용자가 기간 선택(7일/30일/90일/365일)을 변경하면, THE 시스템 SHALL 가치 시계열 및 벤치마크 비교 차트를 변경된 기간에 맞추어 다시 표시한다.

## AC-10: 빈 데이터 빈 상태 UI (REQ-DASH-007)

IF 선택한 기간에 표시할 스냅샷 또는 보유 데이터가 없으면, THEN THE 시스템 SHALL 해당 차트 영역에 오류 메시지 대신 의미 있는 빈 상태 안내를 표시한다.

## AC-11: 로딩 중 표시 (REQ-DASH-008)

WHILE 대시보드 데이터를 조회하는 중이면, THE 시스템 SHALL 각 차트 영역에 로딩 표시를 노출한다.

## AC-12: 소유권 위반 404 (REQ-DASH-009)

IF 사용자가 자신이 소유하지 않은 포트폴리오의 대시보드 데이터를 요청하면, THEN THE 시스템 SHALL 자원을 찾을 수 없음으로 응답한다.

## AC-13: scipy 미사용 (REQ-DASH-NFR-001)

THE 시스템 SHALL 대시보드 집계 계산을 표준 산술 연산만으로 수행하며 외부 과학 계산 라이브러리를 사용하지 않는다.

## AC-14: 순수 함수 분리 (REQ-DASH-NFR-002)

THE 시스템 SHALL 섹터 집계·자산유형 배분·가치 시계열 필터 로직을 데이터베이스 연결 없이 단독으로 호출하고 검증할 수 있는 순수 함수로 제공한다.

## AC-15: 소유권 위반 자원 비노출 (REQ-DASH-NFR-003)

IF 소유권 위반 요청이 들어오면, THEN THE 시스템 SHALL 포트폴리오의 존재 여부를 응답에서 구분할 수 없도록 처리한다.

## AC-16: 차트 컴포넌트 props 구동 (REQ-DASH-NFR-004)

THE 시스템 SHALL 대시보드 차트 컴포넌트를 외부 props로만 구동하며 컴포넌트 내부에 특정 포트폴리오 식별자를 고정하지 않는다.

## AC-17: 허용되지 않은 기간 거부 (REQ-DASH-NFR-005)

IF 7일/30일/90일/365일 이외의 기간 값으로 가치 시계열을 요청하면, THEN THE 시스템 SHALL 해당 요청을 거부한다.
